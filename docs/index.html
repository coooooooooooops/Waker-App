What it is

Dolphin’s core, in a free Mac app.

Waker links Dolphin’s core libraries directly, so it boots the game itself instead of driving a Dolphin install. The result feels like a real Mac app.

⚡

Embedded core

Dolphin’s emulation core runs inside Waker. No separate emulator to install or configure.

🎮

One-click play

Choose your disc, see GZLE01 verified, press Play. The game opens in its own window.

💾

Save states

F1–F8 save to eight slots, Shift+F1–F8 load. Resume straight from the launcher menu.

🖥️

Widescreen & 1×–4×

True 16:9, fullscreen, and internal resolution up to 4× for crisp Outset Island seas.

🎨

HD texture packs

Drop packs into Waker’s folder and flip one switch to load them.

FAQ

Frequently asked

What are the system requirements?
MacApple Silicon (the bundled core is arm64). Intel Macs aren’t supported.
macOS13 Ventura or newer
GameThe Wind Waker (USA), game ID GZLE01, as a plain .iso or .gcm.
Does Waker include the game?

No. Waker contains no game data. You need your own copy of the USA disc image.

Can I use .rvz, .gcz or .wbfs files?

Not directly. Compressed formats are rejected, so convert them to a plain ISO first.

Why does macOS say the app can’t be opened?

The build is signed ad-hoc and not notarised. Right-click the app, choose Open, then Open again. If it’s still refused, clear the quarantine flag (see Setup).

I get a black window, then the app closes.

Check ~/Library/Application Support/Waker/DolphinUser/Logs/dolphin.log. “The file could not be read” usually means the disc is in iCloud Drive and hasn’t downloaded locally yet.

Where do saves and settings live?

Everything is in ~/Library/Application Support/Waker/, including settings, key bindings, save states and the emulator user folder.

Something is broken. Where do I report it?

Open an issue on GitHub.

Install

Setup guide

Four steps from download to Outset Island.

Download Waker

Grab Waker.dmg from the latest release below.

Drag to Applications

Open the DMG and drag Waker into Applications.

First launch

Right-click (or Control-click) the app, choose Open, then Open again. If macOS still refuses, run this once in Terminal:

xattr -dr com.apple.quarantine /Applications/Waker.app

Choose your disc & play

Click Choose Disc Image… and pick your .iso. When you see USA disc ready · GZLE01, press Play.
